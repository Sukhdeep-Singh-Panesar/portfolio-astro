## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

`git clone https://github.com/Sukhdeep-Singh-Panesar/portfolio-astro.git`

**2. Navigate to the project directory**

`cd portfolio-astro`

**3. Install dependencies**

`npm install`

**4. Start the development server**

`npm run dev`

**5. Open the website**

Visit [http://localhost:4321](http://localhost:4321).

## Available Commands

| Command | Description |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build locally |

## Deployment

The portfolio is hosted on **Vercel** and connected to this GitHub repository.

Changes merged into the `main` branch automatically trigger production deployments.
